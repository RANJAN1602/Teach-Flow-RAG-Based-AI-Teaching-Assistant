# Teach-Flow-RAG-Based-AI-Teaching-Assistant
• Built a RAG pipeline that transcribes lecture videos (FFmpeg + Whisper large-v2, Hindi-to-English), embeds timestamped chunks with BGE-M3  Ollama, and retrieves the top-5 matches using cosine similarity. • Used Llama 3.2 to answer student queries by pointing to the exact video and timestamp, with off-topic questions handled through prompt design
